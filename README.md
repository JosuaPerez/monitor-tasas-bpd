# 🏦 Monitor de Tasas - Banco Popular Dominicano

Aplicación desarrollada en Python y Streamlit que se conecta a la API Sandbox del Banco Popular para visualizar tasas de préstamos y calcular cuotas en tiempo real.

## 🚀 Características
- Conexión segura OAuth 2.0 con la API de IBM/BPD.
- **Dashboard:** Visualización de tasas actuales.
- **Simulador de Préstamos:** Cálculo de cuotas con amortización y gráficos.
- **Inversiones:** Calculadora de retorno para certificados financieros.

## 🛠️ Tecnologías
- Python 3.10+
- Streamlit
- Pandas
- Requests
